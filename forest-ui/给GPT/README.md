# 知了森林 · 森林页设计简报（给 GPT）

> 你是一名 UI 设计师。请阅读本文件 + 同目录的数据文件，设计「知了森林」产品**进入后**的「森林页」，并产出 HTML/CSS/JS 代码。
> 这是「封面之后」的新页面，**不要覆盖封面**。封面（`reference/cover.png`）只作为风格参考。

---

## 一、产品是什么（一句话）

「知了森林」是一个**会自己长大的兴趣森林**：用户在知乎点赞/收藏的内容，AI 自动归纳成主题，在屏幕上长成一棵棵树。用户什么都不用做，森林自己会长。

## 二、已定风格（不要推翻，保持一致）

封面 `reference/cover.png` 已定稿，画风：**手绘水彩 / 治愈系 / 低饱和 / 米白纸底 / 森林雾气感**。

- 配色：米白 `#FAF9F2`、标题深鼠尾草绿 `#4F5D4B`、灰绿 `#6E7E6A`
- 字体：标题用书法体（华文行楷 / 楷体 / KaiTi / STKaiti），正文用 微软雅黑 / PingFang SC
- 画布：**16:9 横版，`viewBox="0 0 1600 900"`**
- 森林页复用同一张背景图 `assets/背景图.jpg`，但**加高斯模糊**（放大 1.05~1.1 倍再模糊，避免边缘透白），让前景的树和按钮「浮」出来。

## 三、这个页面要做什么

森林页 = **模糊背景 + 树/叶主体 + 功能按钮**。按优先级包含这些功能：

1. **森林画面**：把 `forest-data.json` 里的树画出来（手绘水彩风）。树 = 大主题，叶 = 小主题。
2. **生长状态可视化**：树的大小/冠形表达 `stage`（flourishing 繁茂 / mature 成熟 / young 幼树）；叶的颜色表达 `state`（fresh 绿 / fading 黄 / withered 棕、垂落）。
3. **快进演示**：底部一条 30 天时间轴，拖动回放「荒芜 → 长成森林」。
4. **浇水 / 修剪**：点一片叶弹出两个小按钮「浇水」（继续看，叶由黄转绿）／「修剪」（不感兴趣，叶落下）。
5. **知了精灵**：一只小知了在树间飞，偶尔停在某棵树旁冒一句气泡（如「这棵树最近长势很好」）。
6. **顶部 HUD**：左上 头像 + 昵称 + 「第 N 天」；右上「光合报告」「农夫日记」两个入口按钮。
7. **光合报告 / 农夫日记**：两个弹层（盖在森林上，点 X 关闭）。
   - 光合报告 = 每天一张卡片，总结昨天读的内容 + AI 摘要。
   - 农夫日记 = 上下两层：上「灵魂画像」（你是深潜型探索者），下「变化日记」（这周心理学猛涨、健身叶在枯萎），两层互相印证。

## 四、数据说明（forest-data.json）

| 分组 | 字段 | 含义 |
|---|---|---|
| persona | displayName | 灵魂画像标题用（如「深潜型探索者」） |
| persona | nickname / bio / tags | 用户昵称、简介、标签 |
| trees | name / category | 主题名 / 分类（tech/business/life/science…） |
| trees | stage | 成长阶段：flourishing 繁茂 / mature 成熟 / young 幼树 / sprout 新芽 |
| trees | totalContentCount | 这棵树下收藏的内容条数 |
| trees | leafIds | 这棵树上挂的叶子 id 列表 |
| leaves | name / summary | 子主题名 / 一句话摘要 |
| leaves | state | 健康度：**fresh 新鲜 / fading 发黄 / withered 枯萎**（决定颜色） |
| leaves | waterCount | 被浇水次数 |
| layout | x / y | 树的**确定性坐标**（0~1 归一化，×1600 / ×900 得到像素位置），用这个摆树，不要随机 |
| layout | scale | 树的显示大小倍率 |

**30 天剧情线**（做快进 / 农夫日记用）：
- 第 1~5 天：4 棵树快速长出（职业发展、健身、创业与产品、人工智能）
- 第 14 天：新树「心理学」出现 + 人工智能树长出新叶「大模型落地」（新兴趣冒出来）
- 第 13 天起：健身停止更新 → 叶枯萎
- 第 15~16 天：创业与产品的两片叶枯萎
- 第 30 天：人工智能树一直旺盛（3 片叶全 fresh，长成 flourishing），其它树慢慢淡出
- 这条线呼应人设：「深潜型探索者 —— 60% 收藏都在一棵树上」

## 五、内容数据（sample-content.json）

光合报告 / 农夫日记卡片会引用单条内容，字段：`title`（标题）、`excerpt`（摘要）、`url`（原文链接）、`voteUpCount`（点赞数）、`source`（search/like/favorite）、`category`、`interactedAt`。

**合规要求（务必遵守）**：展示内容必须保留作者署名和 `url` 链接；不得声称内容由本应用或当前用户创作；这些内容来自知乎公开内容，时间线是演示编排。
