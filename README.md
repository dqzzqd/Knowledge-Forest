# 知了森林 · Knowledge Forest

> 一个会自己生长的兴趣森林。把你刷过的、收藏的、点赞过的内容，长成一片看得见的森林。

**知乎黑客松 2026 · 知识炼金场赛道（学习工具与知识生产）**

---

## 它解决什么问题

我们在知乎点赞收藏了几百篇深度长文、专业干货，在评论区高谈阔论，在收藏夹里囤积着「未来的自己」。
可当深夜点开那个庞大的收藏夹时，心底泛起的是心虚与虚无——**知识只是被「看见」了，从未被真正理解、吸收**。

这就是「**收藏即知晓**」的幻觉。而知了森林想做的是：

> **你继续正常刷知乎，森林自己会长。**

- 收藏与点赞过什么，AI 自动归纳成主题 → 长成一棵棵树
- 大主题是树，小主题是叶子；内容越多，树越茂盛
- 每天打开，森林因为昨天的浏览行为**自动多长一点**
- 知了精灵帮你修剪枯枝、浇水、清理落叶
- 可以看到「光合作用报告」（昨日输入总结）与「农夫日记」（你的兴趣变化）

名字里的**知了**是双关：知了是蝉，也是「知道了」。
**你以为你知道了，但你真的知道了吗？**

## 快速开始

```bash
npm install
npm run dev
```

打开 http://localhost:3000 即可看到森林。

> 国内网络请先把 npm 源指向镜像，否则 `npm install` 会超时：
> `npm config set registry https://registry.npmmirror.com`

其他命令：

```bash
npm run build   # 生产构建（会校验 TypeScript）
npm run lint    # 代码检查
```

## 演示数据说明

**内容是真的，时间线是编排的。**

- 标题、摘要、链接均来自**知乎真实作者的创作**，经知乎官方 CLI 检索获得
- 浏览时间、主题归属为**演示编排**，用于呈现「生长」效果
- **不是**真实用户的真实浏览历史

三个演示用户（`user-a` / `user-b` / `user-c`）各有 30 天、不同结构的数据，完整覆盖四类变化事件：
**新树 / 猛增 / 枯萎 / 复苏**。

数据字段与使用方式见 [`mock-data/README.md`](./mock-data/README.md)，格式规范见 [`docs/接口契约.md`](./docs/接口契约.md)。

## 技术栈

| 层 | 选型 |
|----|------|
| 框架 | Next.js 16（App Router） + TypeScript |
| 样式 | Tailwind CSS v4 |
| 可视化 | SVG（手绘治愈风，不引入 3D） |
| AI | Claude API（主题聚类 · 摘要 · 叙事） |
| 数据 | 演示阶段为 JSON 文件，不引入数据库 |

设计原则：**AI 只负责语义判断，森林的状态与布局由确定性代码控制**——AI 可以失败，森林不能崩。
