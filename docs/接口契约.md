## 0. 给 AI 工具的强制指令（请连同本文档一起粘贴）

```

6. 可选字段确实无值时返回 null，不要省略字段本身。
```

## 1. 全局约定

| 项目 | 约定 |
|------|------|
| 命名风格 | **camelCase**（`treeId`，不是 `tree_id`） |
| 时间格式 | ISO 8601 带时区 `2026-09-13T08:30:00+08:00`；纯日期 `2026-09-13` |
| 时区 | 统一 `+08:00` |
| ID 前缀 | `tree_` / `leaf_` / `content_` / `report_` / `entry_` / `signal_` |
| 数组 | 无数据返回 `[]`，**禁止 null** |
| 数值范围 | 权重 / 分数类统一 `0-100`；坐标统一归一化 `0-1` |

### ID 生成与稳定性（★ 极重要）

- `contentId` 格式：`content_<知乎ID>`，例：`content_1234567`
- `treeId` 格式：`tree_<英文短名>`，例：`tree_ai`、`tree_startup`
- `leafId` 格式：`leaf_<所属树短名>_<叶子短名>`，例：`leaf_ai_agent`
- **`treeId` 一旦生成，跨天不得改变。** 第二次同步时必须复用已有树的
  `treeId`，绝不允许重新聚类生成新 ID，否则森林会每天洗牌。

## 2. 枚举定义（封闭集合，不得自创）

### 2.1 内容来源 `ContentSource`

| 值 | 含义 |
|------|------|
| `favorite` | 收藏 |
| `like` | 点赞 |
| `search` | 搜索 |

### 2.2 兴趣大类 `TopicCategory`

**这个枚举同时决定前端配色，双方必须一致。**

| 值 | 含义 | 颜色 HEX |
|------|------|---------|
| `tech` | 科技 | `#4A90D9` |
| `humanities` | 人文 | `#5BA87A` |
| `business` | 商业 | `#D9A441` |
| `science` | 科学 | `#7B68C4` |
| `life` | 生活 | `#E08A5F` |
| `arts` | 艺术 | `#C96B9B` |
| `social` | 社会 | `#6BA3B8` |
| `other` | 其它（兜底，AI 拿不准时用这个） | `#9E9E9E` |

### 2.3 树的生长阶段 `TreeStage`

按叶子数量推进（阈值供参考，前端可微调）：

| 值 | 含义 | 叶子数 |
|------|------|--------|
| `seed` | 种子 | 0 |
| `sprout` | 幼苗 | 1-2 |
| `young` | 小树 | 3-5 |
| `mature` | 成树 | 6-10 |
| `flourishing` | 繁茂 | 11+ |

### 2.4 树叶状态 `LeafState`

| 值 | 含义 |
|------|------|
| `fresh` | 新鲜（近期活跃） |
| `fading` | 枯萎中（久未活跃） |
| `withered` | 已枯萎（超过阈值未活跃） |

### 2.5 知了精灵动作 `CicadaAction`

| 值 | 含义 |
|------|------|
| `idle` | 待机（在森林中悬停） |
| `fly` | 飞行中（前往目标树） |
| `prune` | 修剪中 |
| `water` | 浇水中 |
| `sweep` | 清理枯叶中 |

### 2.6 农夫日记事件类型 `DiaryEventType`

| 值 | 含义 |
|------|------|
| `newTree` | 长出了一棵新树（全新兴趣） |
| `surge` | 猛烈增长（某主题关注度骤升） |
| `decay` | 衰退（某主题久未关注） |
| `revive` | 复苏（浇过水的枯叶重新活跃） |

### 2.7 用户反馈动作

| 值 | 含义 |
|------|------|
| `prune` | 修剪（负向信号，不感兴趣） |
| `water` | 浇水（正向信号，想继续看） |

## 3. 核心数据模型

> 用 TypeScript 描述。非 TS 项目请照抄字段名与类型。

```ts
/** 一条原始内容（来自知乎浏览历史） */
interface ContentItem {
  contentId: string;          // "content_1234567"
  title: string;              // 标题
  excerpt: string | null;     // 摘要/正文片段
  url: string | null;         // 原文链接
  source: ContentSource;      // favorite | like | search
  category: TopicCategory | null;  // AI 归类结果；未归类为 null
  voteUpCount: number;        // 知乎赞同数，0 表示无数据；用于筛选"高质量输入"
  interactedAt: string;       // "2026-09-13T08:30:00+08:00"
}

/** 叶子 = 小主题 */
interface Leaf {
  leafId: string;             // "leaf_ai_agent"，跨天稳定
  treeId: string;             // 所属树
  name: string;               // 小主题名，如 "AI Agent"
  summary: string;            // AI 生成的摘要，1-2 句
  contentIds: string[];       // 关联的 ContentItem
  state: LeafState;           // fresh | fading | withered
  createdAt: string;
  lastActiveAt: string;       // 最后一次相关内容的时间
  waterCount: number;         // 被浇水次数，初始 0
}

/** 树 = 大主题 */
interface TopicTree {
  treeId: string;             // "tree_ai" ★ 跨天不得变化
  name: string;               // 大主题名，如 "人工智能"
  category: TopicCategory;
  stage: TreeStage;
  leafIds: string[];          // 树上的叶子
  totalContentCount: number;  // 累计内容数，决定树的视觉大小
  createdAt: string;
  lastGrownAt: string;        // 最后一次生长时间
  prunedLeafIds: string[];    // 被用户修剪掉的叶子
}

/** 树的布局坐标（由后端算好，前端直接渲染） */
interface TreeLayout {
  treeId: string;
  x: number;                  // 归一化 0-1
  y: number;                  // 归一化 0-1
  scale: number;              // 视觉缩放 0.6-1.4（按 totalContentCount 算）
}

/** 知了精灵状态 */
interface CicadaState {
  action: CicadaAction;
  targetTreeId: string | null;  // 当前飞向 / 操作的树
  line: string;                 // 当前对白（AI 生成）
  updatedAt: string;
}

/** 森林状态 —— 前端渲染的唯一数据源 */
interface ForestState {
  userId: string;
  generatedAt: string;
  trees: TopicTree[];
  leaves: Leaf[];             // 扁平存储，通过 treeId 关联
  layout: TreeLayout[];
  cicada: CicadaState;
}

/** 光合作用报告 */
interface ReportHighlight {
  treeId: string;
  treeName: string;
  category: TopicCategory;
  summary: string;            // AI 摘要
  contentIds: string[];
}

interface PhotosynthesisReport {
  reportId: string;           // "report_20260913"
  userId: string;
  date: string;               // "2026-09-13"（本地日期）
  headline: string;           // 一句话总结
  highlights: ReportHighlight[];
  stats: {
    newLeafCount: number;
    newTreeCount: number;
    totalContentCount: number;
  };
}

/** 农夫日记条目 */
interface DiaryEntry {
  entryId: string;            // "entry_20260913_01"
  userId: string;
  createdAt: string;
  periodStart: string;
  periodEnd: string;
  eventType: DiaryEventType;
  treeId: string;
  treeName: string;
  leafIds: string[];
  message: string;            // 拟人化叙事文本
  suggestedAction: "water" | "prune" | "none";
}

/** 兴趣画像 */
interface ProfileTrait {
  label: string;              // 如 "求知欲旺盛"
  score: number;              // 0-100
  evidence: string;           // 一句话依据
}

interface PersonalityProfile {
  userId: string;
  generatedAt: string;
  soulType: string;           // 如 "深潜型探索者"
  soulTypeEmoji: string;      // 如 "🌱"
  description: string;        // 150 字以内
  traits: ProfileTrait[];     // 3-5 个
  topCategories: { category: TopicCategory; weight: number }[];  // weight 0-100
}

/** 用户反馈信号（修剪 / 浇水） */
interface FeedbackSignal {
  signalId: string;           // "signal_..."
  userId: string;
  treeId: string;
  leafId: string;
  action: "prune" | "water";
  createdAt: string;
}
```

## 4. 后端 API 契约

**统一响应外壳**（所有接口必须包这一层）：

```json
{ "success": true, "data": {}, "error": null }
```

失败时：

```json
{ "success": false, "data": null, "error": "人类可读的错误信息" }
```

### 接口清单

| 方法 | 路径 | 入参 | 返回 `data` |
|------|------|------|------------|
| GET | `/api/forest` | `userId` | `ForestState` |
| GET | `/api/report` | `userId`, `date`(可选) | `PhotosynthesisReport` |
| GET | `/api/diary` | `userId`, `limit`(可选) | `DiaryEntry[]` |
| GET | `/api/profile` | `userId` | `PersonalityProfile` |
| GET | `/api/trees/:treeId` | `userId` | `{ tree, leaves, contents }` |
| POST | `/api/feedback` | body: `FeedbackSignal`（去掉 signalId/createdAt，由后端补） | `{ ok: true }` |
| POST | `/api/sync` | body: `{ userId }` | `{ newContentCount, newLeafCount, newTreeCount }` |

## 5. AI 层契约

> 每项都是「输入 JSON → 输出严格 JSON」。禁止输出任何解释文字。

### 5.1 主题提取与增量归类

**输入：**

```json
{
  "existingTrees": [
    { "treeId": "tree_ai", "name": "人工智能", "category": "tech" }
  ],
  "newContents": [
    {
      "contentId": "content_1234567",
      "title": "如何理解 RAG 的检索策略",
      "excerpt": "……",
      "source": "favorite",
      "voteUpCount": 208,
      "interactedAt": "2026-09-13T08:30:00+08:00"
    }
  ]
}
```

**输出：**

```json
{
  "assignments": [
    {
      "contentId": "content_1234567",
      "treeId": "tree_ai",
      "leafId": "leaf_ai_rag",
      "treeName": "人工智能",
      "leafName": "RAG",
      "category": "tech",
      "isNewTree": false,
      "isNewLeaf": true
    }
  ]
}
```

**规则：**
- 优先匹配 `existingTrees` 中的树，**匹配不上才**设 `isNewTree: true` 并新建 `treeId`
- 新增树的 `treeId` 必须由 AI 给出英文短名下划线格式：`tree_<slug>`
- 新增叶子的 `leafId` 必须为 `leaf_<树slug>_<叶slug>`
- `category` 只能取 §2.2 的值

### 5.2 摘要生成

**输入：**

```json
{ "items": [ { "contentId": "content_1234567", "title": "…", "excerpt": "…" } ] }
```

**输出：**

```json
{ "summaries": [ { "contentId": "content_1234567", "summary": "一句话摘要" } ] }
```

### 5.3 变化检测（农夫日记）★ 核心差异化

**输入：**

```json
{
  "periodStart": "2026-09-12T00:00:00+08:00",
  "periodEnd": "2026-09-13T00:00:00+08:00",
  "trees": [ { "treeId": "tree_ai", "name": "人工智能", "category": "tech" } ],
  "leafActivity": [
    {
      "leafId": "leaf_ai_agent",
      "treeId": "tree_ai",
      "name": "AI Agent",
      "contentCountBefore": 3,
      "contentCountAfter": 9,
      "lastActiveAt": "2026-09-12T23:10:00+08:00"
    }
  ]
}
```

**输出：**

```json
{
  "events": [
    {
      "eventType": "surge",
      "treeId": "tree_ai",
      "treeName": "人工智能",
      "leafIds": ["leaf_ai_agent"],
      "message": "这周你对「AI Agent」的关注猛地涨了起来，一下子多长出 6 片叶子。",
      "suggestedAction": "water"
    }
  ]
}
```

**规则：**
- `eventType` 只能取 §2.6 的值
- 无显著变化时返回 `{ "events": [] }`
- `message` 用拟人化、治愈系语气，第二人称"你"，不要用"用户"

### 5.4 光合作用报告

**输入：**

```json
{
  "date": "2026-09-13",
  "highlights": [
    {
      "treeId": "tree_ai",
      "treeName": "人工智能",
      "category": "tech",
      "contentIds": ["content_1234567"]
    }
  ],
  "stats": { "newLeafCount": 5, "newTreeCount": 1, "totalContentCount": 18 }
}
```

**输出：**

```json
{
  "headline": "今天你在人工智能的森林里走了很远。",
  "highlights": [
    { "treeId": "tree_ai", "summary": "你连续读了 4 篇关于 RAG 的文章，像是在给这棵树浇水。" }
  ]
}
```

### 5.5 兴趣画像

**输入：**

```json
{
  "topCategories": [ { "category": "tech", "weight": 62 } ],
  "sampleTitles": ["如何理解 RAG 的检索策略", "Agent 的记忆设计"],
  "treeStats": [ { "treeId": "tree_ai", "name": "人工智能", "leafCount": 12, "totalContentCount": 42 } ]
}
```

**输出：** 直接输出 `PersonalityProfile` 的字段

```json
{
  "soulType": "深潜型探索者",
  "soulTypeEmoji": "🌱",
  "description": "你不太追逐热点，更喜欢把一个领域挖到底。……（150 字以内）",
  "traits": [
    { "label": "求知欲旺盛", "score": 88, "evidence": "近 7 天新增 5 片叶子，其中 4 片属于同一棵树。" },
    { "label": "专注深潜", "score": 76, "evidence": "人工智能一棵树占了全部内容的 62%。" },
    { "label": "兴趣收敛", "score": 54, "evidence": "新增长兴趣仅 1 个，更多是在既有主题上加深。" }
  ],
  "topCategories": [ { "category": "tech", "weight": 62 } ]
}
```

**规则：** `traits` 输出 3-5 个，`score` 为 0-100 整数

### 5.6 知了精灵台词

**输入：**

```json
{ "action": "water", "treeName": "人工智能", "context": "该树本周新增 6 片叶子" }
```

**输出：**

```json
{ "line": "这棵人工智能树最近喝饱水啦，叶子亮晶晶的～" }
```

**规则：** 单句，25 字以内，治愈系，可带一个颜文字或符号

## 7. 提交前自查清单

任何人在提交代码前，逐条确认：

- [ ] 我用的字段名和本文档**逐字一致**（没有 `tree_id` / `treeName` 混用）
